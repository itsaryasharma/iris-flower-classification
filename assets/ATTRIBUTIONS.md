# Image attributions

The photographs in this folder are **illustrative only**. They show what each species looks like; the
model never sees images. It uses only the four numeric measurements entered in the app.

All three images come from Wikimedia Commons. The licence was checked through the Commons API on
19 October 2026. They were cropped and resized to 480 × 360 px; no other changes were made. These resized
copies are distributed under the same licences as the originals.
